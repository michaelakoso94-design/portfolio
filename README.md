# iamkoso.com

Michaela Koso's portfolio. Built with [Astro](https://astro.build), deployed on Netlify.

- `npm install` then `npm run dev` to work locally
- Case studies live in `src/content/work/*.md` (one file per project)
- Images go in `public/images/<project>/` and are referenced as `/images/<project>/file.jpg`
- Set a project's card image with `cover:` in its frontmatter
